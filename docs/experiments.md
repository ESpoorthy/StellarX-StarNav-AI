# Experiment Tracking

This document serves as the canonical experiment log for StellarX-StarNav-AI.
Each experiment entry follows a consistent template to ensure reproducibility and comparability across runs.

> **Instructions:** Copy the template below for each new experiment. Fill in all fields.
> Never edit a completed experiment record — add a new entry instead.
